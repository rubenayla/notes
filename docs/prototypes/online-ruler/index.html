Offline screen ruler

A self-contained ruler that keeps working without the internet.

  • Calibrate once for each display and keep browser zoom at 100%.
  • Click anywhere to add a guide line. Click a guide to remove it.
  • 1, 2, 3 switch units.
  • F toggles fullscreen; D changes theme; Esc clears guides.
  • The ruler, interface, and saved calibration use no network connection.
